# SKU 种草内容增长工作台：详细需求规格

版本：V0.1

日期：2026-08-21

用途：产品、设计、研发和测试联合评审

## 1. 范围和约定

### 1.1 MVP 业务边界

- 用户：个体创作者/小店主。
- 地区与语言：中国大陆、中文内容。
- 平台：导出规格同时覆盖抖音与小红书；自动连接在 MVP 非依赖项。
- 内容：图片组 + 一种由图片派生的循环 MP4/短视频。
- 数据：手工/CSV 为主，官方 API 作为可替换适配器。
- 发布：人工确认；无平台官方回执时不能标记为已发布。

### 1.2 优先级

- `P0`：MVP 闭环必需。
- `P1`：需要平台能力或达到验证门槛后实现。
- `P2`：规模化和智能化能力。

## 3. 需求详述与验收

### SKU-001 新建 SKU

#### 需求

用户可通过以下方式创建 SKU：

1. 手动填写。
2. 上传 CSV。
3. 粘贴公开商品链接并由系统尝试解析；失败时回退到手动填写。

必填字段：名称、类目、至少一张商品图、至少一个可验证卖点。可选字段：规格、材质、颜色、容量、价格、商品链接、目标人群、禁用表达。

#### 验收用例

- Given 用户填写必填字段，When 保存，Then 创建 `SKU(draft)` 和首个 `ProductSnapshot`。
- Given 链接解析失败，When 返回结果，Then 保留已填数据并显示可手动补录的字段，不清空页面。
- Given CSV 存在重复外部 SKU ID，When 导入，Then 进入预览并要求选择跳过、更新或新建，不静默覆盖。
- Given 商品图上传部分失败，When 其他字段成功，Then 保存草稿并列出失败文件及重试入口。

### SKU-002 商品事实确认

#### 需求

每个抽取字段显示值、来源、置信度和是否已由用户确认。关键事实未确认时不可进入发布，但可以试生成带水印/低清候选。

#### 验收用例

- Given 材质来源不明确，When 系统展示事实卡，Then 状态为 `needs_confirmation`，不得用模型猜测。
- Given 用户修改容量，When 保存，Then 创建新 `ProductSnapshot`，历史生成仍指向旧快照。
- Given 商品价格改变，When 更新，Then 已发布历史内容不被改写，新内容默认使用新快照。

### AST-001 素材与授权

#### 需求

素材分类：商品原图、细节图、场景参考、人物/手模、品牌元素、竞品参考。记录来源、上传人、授权状态、保留期和哈希。

#### 验收用例

- 未确认可使用权的人物图只能保存为 `restricted`，不可进入生成。
- 相同哈希文件重复上传时复用对象但保留新的业务关联。
- 用户删除素材时，系统展示受影响的草稿/模板；历史审计引用保留不可逆摘要，不保留可下载原图（依合规策略）。

### BRF-001 创意简报

#### 需求

输入：SKU、平台、目标、受众、卖点、场景、人物、动作、构图、风格、比例、负面约束。系统输出 3 个角度，每个角度包含：Hook、核心卖点、场景、视觉瞬间、内容形式、为什么适合此受众。

#### 验收用例

- 三个角度至少在一个主要变量上有明确差异。
- 角度不能引入事实卡没有支持的功效、材质、价格或赠品。
- 用户可锁定商品/风格字段，只重新生成角度。

### GEN-001 图片生成任务

#### API 语义

`POST /generation-jobs` 必须接收客户端幂等键。任务返回 `job_id`，后续轮询或回调更新状态。

#### 状态

`queued → processing → needs_review → ready`，或进入 `failed/cancelled`。

#### 验收用例

- 同一幂等键重复提交只产生一个计费任务。
- App 切后台、网络中断或刷新页面后任务仍可恢复。
- 部分候选失败时成功候选可审核，任务标记 `partial_failure` 而非整体丢失。
- 重试前显示是否返还额度、预计新增费用和将继承的变量。
- 每个结果保存 `sku_snapshot_id`、`prompt_version_id`、模型、参数、参考图顺序、耗时和成本。
- 用户采用候选前必须完成商品一致性清单。

### GEN-002 视频/轻动效

#### 需求

基于 `ready` 的图片版本派生 5–15 秒 MP4。MVP 支持轻微推拉、平移、光影/花叶等环境运动；商品形变与新增文字默认禁止。

#### 验收用例

- 原始图片版本和视频版本保持父子关系。
- 目标平台比例、时长、码率、文件体积和安全区校验失败时不能进入发布。
- 使用音乐必须记录授权来源；无授权时使用静音或用户自有音频。
- 如提供 Apple Live Photo，必须生成配对的 HEIC/JPEG + MOV 资产并保存配对元数据；GIF/MP4 不得标为 Live Photo。

### REV-001 审核

#### 审核项

1. 商品外观：轮廓、材质、花纹、颜色、尺寸关系、可见文字。
2. 文案事实：价格、规格、功效、赠品、时效和使用体验。
3. 权利：人物肖像、音乐、品牌、场景/图片来源。
4. 平台：比例、时长、标签、AI/商业推广披露。

#### 验收用例

- 自动检测只能提出风险，最终结果为用户/审核人确认。
- `changes_requested` 必须指向资产或文案的具体字段。
- 审核通过后修改商品快照、素材或正文会使审批失效并重新进入 `pending`。

### CNT-001 内容包

#### 需求

支持平台模板：图片顺序、封面、标题、正文、标签、CTA、商品挂载占位、AI/推广披露。

#### 验收用例

- 所有文案事实可追溯到商品事实卡或用户明确输入。
- 超出平台字段长度、安全区或格式要求时给出具体修复建议。
- 标题/标签多版本必须挂在同一个 `CreativeBrief` 下。

### PUB-001 导出和手工发布回填

#### 需求

导出包包括命名规范化的素材、`content.txt`、封面和发布清单。系统分享与下载分开记录。用户可回填平台帖子 URL/ID。

#### 验收用例

- `exported` 不触发 `post_published` 事件。
- 回填 URL 需要平台域名与格式校验；无法确认时标记 `manual_unverified`。
- 同一版本重复导出保留次数，不重复创建内容版本。

### PUB-002 OAuth 与官方发布

#### 前置条件

- 开发者主体、应用类目、回调域名和目标 API 权限已由平台审批。
- 已在测试/沙箱账号验证发布、状态回调和限流。

#### 验收用例

- OAuth 使用 state/PKCE（平台支持时）、最小 scope；token 加密并可撤销。
- 发布前用户确认具体账号、内容、SKU/商品、公开范围和时间。
- 只有平台返回正式 `post_id` 后状态为 `published`。
- 超时进入 `unknown` 并先查询状态，不自动重复提交。
- scope 失效或账号解绑后阻止发布，但不删除本地内容。

### DAT-001 手工/CSV 数据

#### 需求

支持曝光、播放、点赞、收藏、评论、分享、商品点击、加购、订单、GMV、退款、佣金。每条数据包含平台、账号、帖子、SKU、统计窗、来源和导入时间。

#### 验收用例

- 无帖子绑定的数据进入待匹配队列，不自动归到最近内容。
- CSV 重复导入按数据源 + 外部键 + 快照时间幂等。
- 实际、手工和估算数据显示不同标签。
- 退款后 GMV 与原始 GMV 分栏，不覆盖原数据。

### INS-001 评论洞察

#### 需求

评论导入后去除不必要的用户名/头像等标识，聚类为：喜欢点、疑问、异议、需求、使用场景、用户原话。生成洞察时展示证据样本。

#### 验收用例

- 用户可删除单条评论或整个导入批次。
- 洞察不能自动成为商品事实；进入 PromptVersion 前需要用户确认。
- 评论不足或样本偏差明显时显示低置信度。

### EXP-001 单变量实验

#### 需求

Experiment 绑定一个 SKU、一个假设、一个主要变量、一个主指标和至少两个 ExperimentArm。记录账号、时段、内容类型和非控制因素。

#### 验收用例

- 两个实验臂若同时改变多个主要变量，系统阻止启动或标记为探索性测试。
- 未达最低样本/观察窗时状态为 `insufficient_data`。
- 平台自然分发、发布时间和账号权重作为限制条件展示。
- 结论只能是 `winner / inconclusive / stopped`，不输出“保证爆款”。

## 4. 非功能需求

### 4.1 可用性

- 生成任务可后台执行，进度按任务而非页面生命周期保存。
- 长任务提供预计范围而非虚假精确倒计时。
- 关键状态均有空态、加载、部分成功、错误、额度不足和权限失效页面。

### 4.2 性能

- 页面接口 P95（不含媒体生成）目标 < 1.5 秒，具体以基础设施基线调整。
- 生成队列需提供并发限制、超时、熔断和供应商回退策略。
- 图片/视频采用分层存储、CDN 和生命周期策略。

### 4.3 可靠性

- 所有计费、配额、发布和数据导入操作必须幂等。
- 媒体生成采用状态机与 outbox/event 机制，避免任务成功但业务状态丢失。
- 发布请求与平台回执分离保存；重试必须先查状态。

### 4.4 安全与隐私

- OAuth token、API key 不进入日志、分析事件或客户端持久明文。
- 对象存储使用租户隔离、短期签名 URL 和服务端权限校验。
- 评论/订单等数据按最小化原则采集，支持删除、导出和授权撤销。
- 所有敏感管理操作写入 AuditLog。

### 4.5 成本

- 每个 GenerationJob 预估与实付成本写入 CostLedger。
- 低清预览、候选数、视频时长和重试策略可配置。
- 展示“单个采纳素材的累计成本”，避免只统计最终一次。

## 5. 错误码建议

| 错误码 | 场景 | 用户处理 |
|---|---|---|
| `SKU_FACT_REQUIRED` | 关键商品事实未确认 | 返回事实卡确认 |
| `ASSET_RIGHTS_UNCONFIRMED` | 素材授权未确认 | 补充授权/更换素材 |
| `GEN_PROVIDER_UNAVAILABLE` | 媒体供应商不可用 | 稍后重试或选择替代模式 |
| `GEN_PARTIAL_FAILURE` | 部分候选失败 | 保留成功结果，单独重试失败项 |
| `QUOTA_INSUFFICIENT` | 额度不足 | 查看成本并充值/减少候选 |
| `CONTENT_REVIEW_REQUIRED` | 修改导致审核失效 | 重新审核 |
| `CHANNEL_NOT_CONNECTED` | 未连接平台 | 导出/系统分享或连接 |
| `CHANNEL_SCOPE_DENIED` | 缺少 OAuth scope | 查看权限说明/重新授权 |
| `PUBLISH_STATUS_UNKNOWN` | 发布请求超时 | 查询平台状态，不重复提交 |
| `METRIC_SOURCE_UNVERIFIED` | 数据来源无法确认 | 标为手工/待核实 |
| `EXPERIMENT_INSUFFICIENT_DATA` | 样本不足 | 延长观察或保持无结论 |

## 6. 研发切分建议

### Sprint A：领域基础

Workspace、SKU、ProductSnapshot、素材上传、权限与审计。

### Sprint B：生成链路

CreativeBrief、PromptVersion、GenerationJob、媒体适配器、AssetVersion、成本/额度。

### Sprint C：内容与审核

候选对比、内容包、ReviewDecision、导出与系统分享。

### Sprint D：结果闭环

PublishRecord、URL 回填、CSV 数据导入、MetricSnapshot、基础看板与实验。

平台 OAuth/自动发布应作为独立 Spike/P1，不进入 MVP 关键路径。

平台优先级：抖音公开存在授权投稿与部分内容数据能力，可优先做 P1 Spike；小红书普通创作者笔记自动发布、互动数据和内容到订单归因未获官方证据，保持导出/分享路径，禁止使用模拟登录、Cookie 托管、RPA 或非公开接口兜底。
