# SKU 创建与查看

当前流程：商品列表 → 创建 SKU → 保存 → 商品详情 → 编辑。

- 创建页固定布局，只输入商品名称。图片横向排列，N 张图片后跟一个相册添加按钮；最多 9 张，满额隐藏添加按钮。
- 底部只有“保存商品”。SKU 编号自动生成，无需填写卖点或描述。
- 详情页只展示商品名称与图片，支持左右查看图片并返回编辑。
- 事实确认、生成、审核和结果页面及其路由已删除，创建或查看 SKU 不触发 AI 请求、生成任务或后台恢复轮询。

SKU 元数据仍保存到 App 沙盒的 `Application Support/Muses/snapshot-v2.json`，图片文件由 `AssetStore` 保存。Realm 定义尚未接入，未迁移旧数据。

## 手工验收

由用户在 Xcode 构建并运行，Codex 仅做静态检查。

1. 检查 0、1、8、9 张图片时的添加框数量、横向滑动、删除后追加及相册取消。
2. 检查空名称不可保存，只填名称可保存并进入详情。
3. 检查详情图片顺序、名称、返回编辑、再次保存及重启后的内容。
4. 检查图片加载失败提示，以及小屏、键盘、大字体和 VoiceOver 可用性。
