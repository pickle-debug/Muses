## 机会评分

`机会分 = (用户价值 + 收入潜力 + 战略差异化) - (实现成本 + 平台/合规风险)`。每项 1-5 分，分数旁写依据，不使用没有证据的精确小数。

## 最小验证问题

- 用户现在用什么方式完成同一任务，耗时和失败点是什么？
- 哪个输入一旦缺失就会使结果不可用（商品链接、佣金、素材、店铺权限、语言/地区）？
- 哪个输出可以在 24 小时内验证（点击、完播、加购、成交、佣金）？
- 哪些数据是平台 API 可得，哪些只能由用户手动补充？
